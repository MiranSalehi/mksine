# Security Policy

**Please do not disclose security-related issues publicly.** See [Reporting a vulnerability](#reporting-a-vulnerability) below.

## Supported Versions

Security fixes are provided for the latest stable release on [Packagist](https://packagist.org/packages/miran/mksine). Upgrade to the newest `miran/mksine` version before reporting issues against older releases.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in MKSine:

1. **Preferred:** open a [private security advisory](https://github.com/MiranSalehi/mksine/security/advisories/new) on GitHub.
2. **Alternative:** email **miransalehi.ms@gmail.com** with a clear description, steps to reproduce, and impact assessment.

Please allow reasonable time for triage and a fix before public disclosure. We aim to acknowledge reports within a few business days.

For non-security bugs, use [GitHub Issues](https://github.com/MiranSalehi/mksine/issues).
