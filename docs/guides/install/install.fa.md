# نصب MKSine

این راهنما برای صاحبان سایت است که MKSine را از صفحهٔ دانلود mksine.com نصب می‌کنند. اگر توسعه‌دهنده هستید و می‌خواهید MKSine را با Composer به یک پروژهٔ لاراول اضافه کنید، [راهنمای Installation](../../01-installation.md) را ببینید.

## پیش‌نیازها

- **PHP نسخهٔ 8.2 یا جدیدتر** با این افزونه‌ها: `ctype`، `curl`، `fileinfo`، `mbstring`، `openssl`، `pdo`، `tokenizer`، `xml`، `zip` و یک درایور دیتابیس (`pdo_mysql` برای MySQL/MariaDB). افزونه‌های `intl`، `sodium` و `gd` هم پیشنهاد می‌شوند. بیشتر هاست‌ها همه را فعال دارند و نصب‌کننده خودش بررسی می‌کند.
- **یک دیتابیس خالی** (MySQL 5.7 به بالا، MariaDB 10.3 به بالا یا PostgreSQL) و یک کاربر با دسترسی کامل به آن. برای سایت‌های کوچک SQLite هم کار می‌کند.
- **دسترسی به فایل‌ها**: File Manager پنل هاست، FTP یا SSH.

## نصب سریع (پیشنهادی)

لازم نیست کل فایل zip را آپلود کنید. یک فایل کوچک آپلود کنید تا خودش MKSine را دانلود کند.

1. دیتابیس را بسازید و PHP نسخهٔ 8.2 یا جدیدتر را انتخاب کنید (مراحل ۱ و ۲ در بخش [هاست اشتراکی](#هاست-اشتراکی-cpanel-directadmin)).
2. فایل `mksine-installer.php` را از mksine.com دانلود کنید و در `public_html` (پوشهٔ وب دامنه) آپلود کنید.
3. آدرس `https://YOURDOMAIN/mksine-installer.php` را باز کنید.
4. **کد امنیتی.** این فایل کنار `public_html` فایل `mksine/SETUP-TOKEN.txt` را می‌سازد. آن را در File Manager باز کنید و کد خط اولش را وارد کنید.
5. PHP، افزونه‌ها، دسترسی پوشه‌ها و فضای دیسک بررسی می‌شوند و محل فایل‌ها نمایش داده می‌شود. روی **دانلود و نصب** بزنید.
6. صفحه را باز نگه دارید. آخرین نسخه به‌صورت تکه‌تکه از GitHub دانلود می‌شود تا روی هاست کند هم به محدودیت زمان نخورد. بعد چک‌سام SHA-256 آن بررسی می‌شود، فایل‌ها استخراج می‌شوند و نصب‌کننده خودش را پاک می‌کند. صفحهٔ پیش‌فرض هاست مثل `index.html` به `index.html.mksine-old` تغییر نام می‌دهد. خط‌هایی که هاست در `.htaccess` گذاشته (مثل نسخهٔ PHP) حفظ می‌شوند.
7. نصب‌کنندهٔ MKSine در مرحلهٔ *پیش‌نیازها* باز می‌شود و لازم نیست کد را دوباره وارد کنید. از [مرحلهٔ ۴](#۴-اجرای-نصب‌کننده) به بعد ادامه دهید.

نکته‌ها:

- برنامه مثل نصب دستی در پوشهٔ `mksine/` **کنار** پوشهٔ وب قرار می‌گیرد. اگر این پوشه از قبل فایل داشته باشد، یا پوشهٔ وب از قبل `index.php` داشته باشد، نصب متوقف می‌شود و می‌گوید چه چیزی را باید حذف کنید.
- اگر هاست شما اجازهٔ دانلود از اینترنت نمی‌دهد، فایل `mksine-{version}-shared-hosting.zip` را خودتان دانلود کنید و کنار `mksine-installer.php` آپلود کنید. نصب‌کننده از همان فایل استفاده می‌کند.
- روی سرور شخصی، اگر ریشهٔ وب پوشه‌ای به نام `public` باشد و کنارش چیز دیگری نباشد (مثلاً `/var/www/example.com/public`)، برنامه در پوشهٔ بالاتر نصب می‌شود و از `mksine-{version}-server.zip` استفاده می‌شود.

## کدام فایل را دانلود کنم؟

| فایل | برای |
| ---- | ---- |
| `mksine-installer.php` | [نصب سریع](#نصب-سریع-پیشنهادی): یک فایل آپلود کنید، بقیه را خودش دانلود می‌کند |
| `mksine-{version}-shared-hosting.zip` | هاست اشتراکی با cPanel، DirectAdmin و پنل‌های مشابه |
| `mksine-{version}-server.zip` | سرور شخصی (VPS) که وب‌سرورش دست خودتان است |
| `SHA256SUMS` | اختیاری: برای اطمینان از سالم بودن فایل دانلودشده (`shasum -a 256 -c SHA256SUMS`) |

## هاست اشتراکی (cPanel، DirectAdmin)

فایل هاست اشتراکی دو پوشه دارد:

```
mksine/        خود برنامه: کد، تنظیمات، فایل‌های دیتابیس؛ هیچ‌وقت به بازدیدکننده نشان داده نمی‌شود
public_html/   فقط فایل‌های عمومی: index.php، CSS، JavaScript، تصاویر
```

برنامه **کنار** `public_html` قرار می‌گیرد، نه داخل آن. به همین دلیل فایل‌هایی مثل `.env` که رمز دیتابیس در آن است هرگز از مرورگر قابل دانلود نیستند.

### ۱. ساختن دیتابیس

- **cPanel:** بخش *Databases* ← *MySQL Database Wizard*. یک دیتابیس، یک کاربر و رمز بسازید و به کاربر دسترسی **All privileges** بدهید.
- **DirectAdmin:** *Account Manager* ← *MySQL Management* ← *Create new Database*.

نام دیتابیس، نام کاربری و رمز را یادداشت کنید. در بیشتر هاست‌ها با نام حساب شما شروع می‌شوند، مثلاً `myuser_mksine`.

### ۲. انتخاب PHP 8.2 یا جدیدتر

- **cPanel:** *Software* ← *MultiPHP Manager* (یا *Select PHP Version*).
- **DirectAdmin:** *Extra Features* ← *Select PHP Version* (یا *Domain Setup* ← نسخهٔ PHP).

### ۳. آپلود و باز کردن فایل

1. **File Manager** را باز کنید و به پوشه‌ای بروید که `public_html` **داخلش** است:
   - cPanel: پوشهٔ خانهٔ حساب، یعنی `/home/USERNAME`
   - DirectAdmin: `/home/USERNAME/domains/YOURDOMAIN`
2. اگر داخل `public_html` صفحهٔ پیش‌فرض هاست هست (`index.html` یا `default.html`)، پاکش کنید. از هر فایل دیگری که آنجاست نسخهٔ پشتیبان بگیرید.
3. فایل `mksine-{version}-shared-hosting.zip` را در همین پوشه آپلود کنید. اگر پنل اجازهٔ آپلود فایل بزرگ نداد، با FTP آپلود کنید.
4. فایل zip را انتخاب کنید و **Extract** بزنید. حالا پوشهٔ `mksine/` کنار `public_html/` است و فایل‌های عمومی داخل `public_html/` قرار گرفته‌اند.
5. فایل zip را پاک کنید.

اگر پوشهٔ وب دامنهٔ شما اسمش `public_html` نیست (دامنه‌های addon معمولاً پوشهٔ جدا دارند)، **محتوای** پوشهٔ `public_html/` را داخل همان پوشه کپی کنید. پوشهٔ `mksine/` باید **در همان پوشه‌ای باشد که پوشهٔ وب داخلش است** و نباید داخل هیچ پوشه‌ای باشد که از مرورگر در دسترس است.

### ۴. اجرای نصب‌کننده

آدرس دامنه را در مرورگر باز کنید. تا وقتی نصب تمام نشده، همهٔ صفحه‌ها به نصب‌کننده در `/install` می‌روند.

1. **زبان:** فارسی یا English را انتخاب کنید.
2. **کد امنیتی:** نصب‌کننده فایلی به نام `SETUP-TOKEN.txt` داخل پوشهٔ `mksine/` می‌سازد. آن را در File Manager باز کنید، کدِ خط اول (مثلاً `K7QF-3MZP-X8RA`) را کپی کنید و وارد کنید. فقط کسی که به فایل‌های شما دسترسی دارد این کد را می‌بیند، پس کس دیگری نمی‌تواند نصب را در دست بگیرد.
3. **پیش‌نیازها:** نصب‌کننده PHP، افزونه‌ها و دسترسی پوشه‌ها را بررسی می‌کند. اگر چیزی کم بود، از پشتیبانی هاست بخواهید فعالش کند و بعد *بررسی دوباره* را بزنید.
4. **دیتابیس:** مشخصات مرحلهٔ ۱ را وارد کنید. آدرس سرور معمولاً `localhost` است. قبل از ذخیره، اتصال آزمایش می‌شود.
5. **سایت و مدیر:** نام و آدرس سایت، زبان سایت، حساب مدیر، قالب و افزونه‌هایی که می‌خواهید فعال شوند. بعداً هم از پنل مدیریت می‌توانید افزونه‌های دیگر را فعال کنید.
6. **نصب:** صفحه را باز نگه دارید. هر مرحله جداگانه اجرا می‌شود تا روی هاست کند قطع نشود. اگر مرحله‌ای ناموفق شد، علت را برطرف کنید و *تلاش دوباره* را بزنید؛ نصب از همان‌جا ادامه پیدا می‌کند.

بعد از پایان، نصب‌کننده خودش بسته می‌شود: آدرس `/install` دیگر وجود ندارد و فایل `SETUP-TOKEN.txt` پاک می‌شود.

### ۵. اضافه کردن cron

MKSine به یک cron نیاز دارد که هر دقیقه اجرا شود، برای کارهای زمان‌بندی‌شده (پشتیبان‌گیری، یادآوری، ایمیل) و صف. صفحهٔ آخر نصب‌کننده خط دقیق را نشان می‌دهد، مثلاً:

```bash
* * * * * php /home/USERNAME/mksine/artisan schedule:run >> /dev/null 2>&1
```

- **cPanel:** *Advanced* ← *Cron Jobs*. گزینهٔ *Once Per Minute* را انتخاب کنید و دستور را وارد کنید.
- **DirectAdmin:** *Advanced Features* ← *Cronjobs*. همهٔ فیلدها را `*` بگذارید و دستور را وارد کنید.

بعضی هاست‌ها به‌جای `php` مسیر کامل PHP را لازم دارند، مثلاً `/usr/local/bin/php` یا `/opt/cpanel/ea-php83/root/usr/bin/php`. مستندات یا پشتیبانی هاست مسیر درست را می‌گوید.

### ۶. بررسی سلامت سایت

به `https://YOURDOMAIN/admin` بروید و **سیستم ← سلامت سیستم** را باز کنید. چند دقیقه بعد از اضافه کردن cron، زمان‌بندی و صف باید **درست** نشان داده شوند. این صفحه هر چیزی را که هنوز نیاز به رسیدگی دارد همراه با راه رفعش نشان می‌دهد.

روی هاست اشتراکی عادی است که *پردازش‌های پس‌زمینه* «غیرفعال» باشد؛ کنسول پنل مخفی می‌شود و بقیهٔ بخش‌ها کار می‌کنند.

## سرور شخصی (VPS)

1. فایل `mksine-{version}-server.zip` را باز کنید، مثلاً در `/var/www/mksine`.
2. به کاربر وب‌سرور اجازهٔ نوشتن در پوشه‌های لازم را بدهید:

   ```bash
   cd /var/www/mksine
   sudo chown -R www-data:www-data storage bootstrap/cache public
   sudo chown www-data:www-data .   # تا نصب‌کننده بتواند .env و SETUP-TOKEN.txt را بسازد
   ```

3. وب‌سرور را روی پوشهٔ `public/` تنظیم کنید. MKSine کانفیگ آماده می‌سازد:

   ```bash
   php artisan mksine:server-config nginx --domain=example.com
   php artisan mksine:server-config apache --domain=example.com
   ```

4. نصب را یا در مرورگر انجام دهید (دامنه را باز کنید؛ مراحل مثل بالاست و `SETUP-TOKEN.txt` در `/var/www/mksine` است) یا در ترمینال:

   ```bash
   cp .env.example .env   # بعد DB_* و APP_URL را تنظیم کنید
   php artisan mksine:install --migrate
   ```

5. cron و اجراکنندهٔ صف را اضافه کنید:

   ```bash
   php artisan mksine:server-config cron
   php artisan mksine:server-config supervisor
   ```

6. دستور `php artisan mksine:doctor` را اجرا کنید و بعد **سیستم ← سلامت سیستم** را در پنل ببینید.

## رفع مشکلات

| مشکل | راه حل |
| ---- | ------ |
| قبل از نصب‌کننده صفحهٔ سفید یا «500 Server Error» می‌آید | نسخهٔ PHP (8.2 به بالا) را بررسی کنید و مطمئن شوید `mksine/storage` و `mksine/bootstrap/cache` قابل نوشتن هستند. متن خطا در `mksine/storage/logs/laravel.log` است. |
| پیام «Composer dependencies require a PHP version» | دامنه از PHP قدیمی استفاده می‌کند. در پنل عوضش کنید (مرحلهٔ ۲). |
| به‌جای نصب‌کننده، صفحهٔ پیش‌فرض هاست می‌آید | فایل `index.html` یا `default.html` را از `public_html` پاک کنید. |
| «فایل کد امنیتی ساخته نشد» | پوشهٔ `mksine/` را قابل نوشتن کنید (دسترسی 755) و صفحه را دوباره باز کنید. |
| «اتصال به دیتابیس برقرار نشد» | آدرس سرور را `localhost` بگذارید و نام کامل دیتابیس و کاربر (با پیشوند حساب) را وارد کنید. مطمئن شوید کاربر روی دیتابیس همهٔ دسترسی‌ها را دارد. |
| یکی از مراحل نصب ناموفق شد | پیام زیر همان مرحله را بخوانید، علت را برطرف کنید و *تلاش دوباره* را بزنید. مراحل تمام‌شده تکرار نمی‌شوند. |
| هشدار «لینک فضای عمومی» در سلامت سیستم | هاست اجازهٔ symlink نمی‌دهد. رسانه‌های آپلودشده کار می‌کنند؛ اگر افزونه‌ای به فایل‌های دیسک public نیاز دارد، از هاست بخواهید symlink را فعال کند. |
| زمان‌بندی «هرگز» یا با تأخیر نشان داده می‌شود | cron اضافه نشده یا مسیر PHP در آن اشتباه است. |

## به‌روزرسانی

به‌روزرسانی هسته با یک کلیک از پنل مدیریت هنوز در دسترس نیست. برای هر نسخه یادداشت‌های انتشار را در mksine.com دنبال کنید. افزونه‌ها و قالب‌ها همین حالا از پنل مدیریت به‌روز می‌شوند.
